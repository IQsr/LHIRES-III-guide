# LHIRES III Practical Guide

A student-focused field guide for operating, calibrating, and troubleshooting the LHIRES III spectrograph at NTU Observatory.

**[Open the practical guide](https://iqsr.github.io/LHIRES-III-guide/)**

## Who this is for

This guide is designed for students preparing for their first observing night, returning observers who need a live checklist, and anyone reducing or troubleshooting LHIRES III data.

## Start with the right path

- **First time here:** follow the Student Quick-Start in order.
- **Observing tonight:** complete the readiness checklist before taking science exposures.
- **Something went wrong:** jump to Troubleshooting.
- **Learning the instrument:** use the interactive simulator and setup overview.

The critical rule is simple: identify at least two Ar–Ne lamp lines and confirm the CCD wavelength window before taking science exposures. A micrometer reading is a guide, not a wavelength calibration.

## What is included

- Ordered first-night workflow
- Persistent observing checklist with printable output
- LHIRES III optical-path overview and interactive simulator
- Grating tuning and wavelength-calibration guidance
- Ne–Ar wavelength atlas
- Data-reduction workflow and annotated examples
- Troubleshooting by symptom
- A real observing case study

## Contributing

Corrections and additions are welcome. When proposing a change:

1. State which instrument configuration and observing date it applies to.
2. Include an example frame or authoritative reference where possible.
3. Keep operational steps short and add a clear success or stop condition.
4. Avoid presenting nominal micrometer settings as calibrated wavelengths.

Open an issue for uncertain guidance. Use a pull request for a verified correction or improvement.

## Local preview

The site is plain HTML, CSS, and JavaScript. Serve the repository with any local static-file server, then open `index.html` through that server so the embedded simulator and assets behave as they do on GitHub Pages.
